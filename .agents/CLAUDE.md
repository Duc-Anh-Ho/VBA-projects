# .agents/

Cross-agent shared config. Lazy-loaded when a tool reads or edits any file under
.agents/. This is the SHARED layer (rules, memory, hooks, tools) that applies to all
agents. Claude-native config lives in .claude/.

Seeded 2026-05-30 from the QA-agent template (see that repo's PORTABLE.md tier
manifest); QA-agent-specific items were skipped, paths adapted to this repo.

## Subfolder map

| Subfolder | Purpose | When to edit |
|---|---|---|
| `memory/` | Cross-agent memory store. MEMORY.md is the auto-loaded index. Subfolders: user/, project/, features/, behaviors/. | When learning a rule, preference, or project fact worth keeping. |
| `rules/` | Style/code rules. `code/vba-conventions.md`, `doc/doc-style.md`. | When formalizing a convention. |
| `hooks/` | Hook scripts (.mjs only). Grouped by event domain: commit/, edit/, memory/, notify/, tools/. | When wiring a new guardrail. See hooks/CLAUDE.md. |

## Top-level files

- `shared-rules.md` - canonical cross-agent behavioral rules (synced into root CLAUDE.md).
- `tools.md` - usage policy for external CLI tools (full-path required).
- `tools.local.json` - per-machine tool paths (gitignored). Generated by /tools-init.
- `commit-checklist.md` - injected by hooks/commit/inject-checklist.mjs before commits.

## Key invariants

- Memory writes MUST go to .agents/memory/<scope>/, never user-level. Enforced by
  hooks/memory/check-write-rules.mjs.
- Hook scripts MUST use the .mjs extension (extension-determined ESM works standalone
  in any project, even one with no package.json).
- A new external tool used in Bash MUST be in tools.local.json with a full path.
  Enforced by hooks/tools/block-unlisted-tool.mjs.
- Markdown under .agents/ and .claude/ MUST be plain ASCII (no bold, em-dash, or
  Unicode arrows). Enforced by hooks/edit/check-doc-style.mjs.

## When editing

- New memory file -> also add a one-line pointer in memory/MEMORY.md.
- New hook -> place under the matching domain folder, use .mjs, register it in
  .claude/settings.json hooks. Document it in hooks/CLAUDE.md.
- New tool -> add it to .claude/skills/tools-init/SKILL.md, then run /tools-init.
